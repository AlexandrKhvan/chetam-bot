# CheTam («Чё там на завтра?») — `@chetam_plan_bot`

Личный Telegram-бот и **Telegram Mini App** на **Python (`aiogram 3` + `FastAPI` + `SQLite`)** для быстрого сбора мыслей, общего пула задач, недельного расписания учёбы (`.docx` и фото), вечернего планирования следующего дня, умных напоминаний и истории выполнения.

## Возможности

- **🧠 Умный разбор «кучи мыслей» (Brain-dump)** — пиши в чат сплошным текстом (`надо сделать лабу, потом купить кофе, завтра в 18:00 зал и срочно сдать отчёт`), бот сам разобьёт на отдельные задачи, вытащит даты, время и приоритет 🔴, с кнопками массового переноса и откатом «Объединить в 1 задачу».
- **📥 Инбокс + 🗂 Общий пул задач (бэклог)** — свежие мысли падают в Инбокс, а дела «когда-нибудь / без жёсткой даты» хранятся в общем Пуле, откуда их удобно забирать в план дня или на вечернем планировании.
- **📅 Живой план дня с галочками** — единая карточка дня: пары/события по времени + задачи с приоритетами + прогресс-бар. Галочки обновляют сообщение на месте без спама.
- **🌙 Вечерний ритуал планирования** (`/plan` + авто-напоминание вечером):
  1. Итоги дня — перенос недоделанного на завтра одним тапом, отправка в Пул или закрытие.
  2. Сборка завтрашнего дня — превью завтрашних пар, выбор из Инбокса и отдельная кнопка **🗂 Взять из пула** с интерактивным выбором.
- **🔔 Умные напоминания и Snooze** (`/remind`, `/reminders`):
  - естественный ввод: `/remind через 30 мин выключить плиту`, `/remind завтра в 10:00 отчёт`, `/remind каждый день в 22:00 витамины`;
  - быстрая кнопка `🔔` на любой задаче (`+15 мин`, `+1 час`, `Сегодня 20:00`, `Завтра 09:00`, своё время);
  - авто-напоминания по задачам с указанным временем и **за 15/30 мин до пар** (настраивается в `/settings`);
  - кнопки переноса **Snooze** (`+15 мин`, `+1 час`, `Завтра 09:00`) и `✅ Сделано` прямо в уведомлении.
- **🎓 Расписание учёбы из `.docx` и фото**:
  - скидывай `.docx` на неделю прямо в чат — встроенный парсер распознаёт таблицы (в том числе многотабличные вузовские сетки с автоматическим фильтром групп вроде `ВМ-21` / `ВМ-22`);
  - для фото/скриншотов подключается Vision/LLM-парсер (`VISION_PROVIDER=gemini` в `.env`).
- **📊 История и статистика** (`/history`) — хронология выполненных ✅, перенесённых ➡️ и невыполненных ❌ дел по дням, сводка за 7 и 30 дней и стрик 🔥.
- **📱 Telegram Mini App** — встроенное веб-приложение внутри Telegram (День, Инбокс/Пул, Вечер, Напоминания, История) с нативной светлой/тёмной темой, тактильным откликом и криптографической проверкой Telegram `initData` (HMAC-SHA256).

## Быстрый старт локально

1. Создай бота у `@BotFather` и получи `BOT_TOKEN`.
2. Создай `.env` из шаблона и укажи `BOT_TOKEN` (и по желанию `ALLOWED_USER_IDS`):
   ```powershell
   Copy-Item .env.example .env
   ```
3. Установи зависимости и запусти бота:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m app.main
   ```

## Деплой через Docker Compose + Caddy HTTPS (AWS Lightsail / EC2)

```bash
cp .env.example .env
# заполни BOT_TOKEN и WEBAPP_URL=https://<your-domain>
docker compose up -d --build
```

Стек поднимает 3 контейнера: `chetam-bot`, `chetam-webapp` (FastAPI) и `chetam-caddy` (автоматический TLS/HTTPS). База SQLite (`WAL`) хранится в `./data/chetam.db`.
