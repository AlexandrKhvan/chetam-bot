# CheTam («Чё там на завтра?») — `@chetam_plan_bot`

Личный Telegram-бот на **Python (`aiogram 3` + `SQLite`)** для быстрого сбора мыслей, загрузки недельного расписания учёбы (`.docx` и фото), вечернего планирования следующего дня, интерактивных галочек и истории выполнения.

## Возможности

- **📥 Инбокс (мгновенный сбор)** — любое текстовое сообщение (или список из нескольких строк) сразу сохраняется во входящие с быстрыми кнопками `На сегодня / На завтра / Важно`.
- **📅 Живой план дня с галочками** — единая карточка дня: пары/события по времени + задачи с приоритетами + прогресс-бар. Галочки обновляют сообщение на месте без спама.
- **🌙 Вечерний ритуал планирования** (`/plan` + авто-напоминание вечером):
  1. Итоги дня — быстро переносишь недоделанное на завтра, обратно в инбокс или отмечаешь выполненным.
  2. Сборка завтрашнего дня — видишь пары на завтра и набираешь задачи из инбокса в один тап.
- **🎓 Расписание учёбы из `.docx` и фото**:
  - Скидывай `.docx` с новым недельным расписанием прямо в чат — встроенный парсер распознает таблицы (построчные и матричные) и списки.
  - Для фото/скриншотов и нестандартных таблиц поддерживается опциональный Vision/LLM-парсер (Gemini / OpenAI-совместимый API).
  - Перед сохранением всегда показывается предпросмотр.
- **📊 История и статистика** (`/history`) — просмотр любого прошедшего дня (выполнено ✅ / перенесено ➡️ / не сделано ❌), сводка за 7 и 30 дней, стрик 🔥.
- **🧩 Архитектура с заделом под Telegram Mini App** — слой данных (`app/db`) и бизнес-логика (`app/services`) полностью отделены от Telegram (`app/bot`).

## Быстрый старт локально

1. Создай бота у `@BotFather` и получи `BOT_TOKEN`.
2. Создай `.env` из шаблона:
   ```powershell
   Copy-Item .env.example .env
   ```
   Укажи в `.env` свой `BOT_TOKEN` (и по желанию `ALLOWED_USER_IDS`, чтобы ботом мог пользоваться только ты).
3. Установи зависимости в виртуальное окружение и запусти бота:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m app.main
   ```

## Распознавание фото расписания (опционально)

Чтобы бот распознавал скриншоты и фотографии расписания, добавь в `.env`:

```env
VISION_PROVIDER=gemini
GEMINI_API_KEY=your_key_here
GEMINI_MODEL=gemini-2.5-flash
```

## Деплой через Docker (AWS EC2 / Lightsail)

```bash
cp .env.example .env
# заполни .env
docker compose up -d --build
```

База SQLite хранится в примонтированной папке `./data/chetam.db`.
